# Publish this as your GitHub profile README

1. Create (or open) a **public** repo named exactly `gabriel-dahan` under your account:
   https://github.com/new?name=gabriel-dahan
2. Copy `README.md` to the repo root.
3. Copy `.github/workflows/snake.yml` into the same repo.
4. Push to `main`, then run **Actions → Generate snake animation → Run workflow**.
5. After it succeeds, uncomment the snake image block at the bottom of the GitHub pulse section in `README.md`.

This folder is only a staging copy inside `comx-app` — it is not your live profile until you push it to `gabriel-dahan/gabriel-dahan`.
