## Who I am

I'm a **French student & developer** shipping product-shaped software — from reading platforms to private mapping tools.

Right now my main focus is **[COMX](https://comx.click/)**: a comics / manga platform with a creator-first approach and gamification, built to go beyond mainstream Webtoon / Tapas-style sites.
